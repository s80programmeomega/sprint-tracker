# components/

Reusable UI pieces used across multiple pages.

These are not tied to any specific route — they are imported and used inside page components or other components.

Examples:
- TaskCard.vue        → displays a single task on the Kanban board
- SprintBadge.vue     → colored badge showing sprint status
- ConfirmModal.vue    → reusable confirmation dialog
- AppButton.vue       → styled button wrapper

Naming convention: PascalCase, descriptive noun — no "Page" suffix.
